# EchoGPT Hub

A modern single-page website for **EchoGPT** — an all-in-one AI workspace with chat, Image Studio, Video Studio, model compare, connectors, and automation behind a single prompt bar.

## Sections Included

- **Navigation**: Glass-morphism sticky header with navigation links and quick access CTAs.
- **Hero**: Concentric ripple motif, headline, action buttons, and animated live application mockup.
- **Ticker / Marquee**: Smooth infinite ribbon showcasing workspace tools.
- **Features**: Bento grid highlighting the 10 tools with PRO badges and shared context overview.
- **AI Models**: Interactive model lineup (Core, Reason, Vision, Studio) with specs and routing chips.
- **Product Preview**: Tabbed real-interface previews for Chat, Image Studio, and Model Compare.
- **Why Choose EchoGPT**: Core value props with interactive before-and-after comparison.
- **Pricing**: Free, Pro (popular highlight), and Team tiers.
- **FAQ**: Smooth expandable accordion answering key questions.
- **Call-to-Action**: Radial ripple conversion band with desktop web and app install actions.
- **Footer**: Workspace and tool navigation, copyright, and contact details.

## Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org) (App Router, Turbopack)
- **Language**: TypeScript 5, React 19
- **Styling**: Tailwind CSS 4, OKLCH bespoke color tokens, customized fonts (Space Grotesk, DM Sans, JetBrains Mono)
- **Components & Icons**: Lucide React, Radix UI primitives, Framer Motion animations

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

To produce a production build:

```bash
npm run build
npm run start
```
